# ktug-or-kr

ktug.or.kr과 www.ktug.or.kr로 들어온 방문자를 한글 TeX 사용자 모임 사이트 [www.ktug.org](https://www.ktug.org/)로 넘기는 GitHub Pages 저장소입니다.

- `CNAME`: www.ktug.or.kr. 루트 ktug.or.kr은 GitHub Pages IP를 가리키고 GitHub가 www로 넘깁니다.
- `index.html`, `404.html`: 같은 내용입니다. 들어온 경로를 그대로 붙여 `https://www.ktug.org/...`로 넘깁니다(JavaScript, 꺼져 있으면 첫 화면으로).
- 사이트 본체는 [ktug-main-site](https://github.com/KoreanTUG/ktug-main-site) 저장소에 있습니다.
